# Ubuntu Touchpad Fix Matebook X

This bash script provides a potential solution for touchpad freezing issues on Huawei Matebook X running Ubuntu. It works by blacklisting commonly problematic kernel modules and ensuring essential ones are loaded, which often resolves hardware compatibility conflicts.

## Language

`bash`

## How to Run

Save the code as 'fix_touchpad.sh', make it executable (`chmod +x fix_touchpad.sh`), and run it with `sudo ./fix_touchpad.sh`. A reboot is required for the changes to take effect.
